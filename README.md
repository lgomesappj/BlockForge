# BlockForge

BlockForge is a decentralized, AI-driven ledger engine that optimizes processing and auto-scaling for data integrity and chain resilience.

BlockForge is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockForge.git`
2. `cd BlockForge`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
